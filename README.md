# Interactive material results

Real-photograph examples and a comparison of DSTex, TRELLIS.2, and ground-truth materials
across reference lighting.

Open `index.html` in a browser. All viewer resources are included; no build is required.

- Drag an object to rotate every view together, or focus it and use the arrow keys.
- Switch the display channel and view lighting using the shared controls.
- Select an input photograph to enlarge it; its source and license are included.
- Scroll the lighting comparison horizontally on small screens.

Keep `models/chunks/` with the model scripts: larger payloads are split without changing
the geometry or texture data. The viewer does not load remote fonts, scripts, or analytics.

Photograph attribution is provided in the page. Third-party library notices are retained
in `vendor/`.
